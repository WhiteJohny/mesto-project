# Mesto

Интерактивный профиль с возможностью делиться фотографиями уникальных мест

## 🚀 Основные функции

- 📷 Создание и удаление карточек мест
- ❤️ Лайки карточек
- ✏️ Редактирование профиля пользователя
- 🌄 Превью фотографий в полном размере
- 📱 Адаптивный интерфейс для всех устройств

## 🛠 Технологии

### Frontend
- **Сборка**: Webpack 5
- **Адаптивность**: Flexbox, Grid Layout, Media Queries
- **Валидация форм**: JavaScript
- **Асинхронные запросы**: Fetch API
